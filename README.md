USAGE: bf [OPTIONS] ... [FILE]

You can use "bf" or whatever you name your executable

Uses a 30,000 long virtual memory tape to run your brainfuck program.
        --help to remember these commands
 -t,	--trace 			 Log out what your program is doing with each instruction
 -md,	--memory-dump 			 Show the memory (aka tape) after program execution
 -mt,	--memory-trace 			 Show the memory (aka tape) after each instruction is executed
 -p,	--show-program 			 Print out the program after it got parsed
